# 議事録おこしの手引き（見本と、迷ったときの判断）

本体の手順で迷ったときに開くファイル。**記入済みの見本**と、**曖昧な言葉の扱い方**が入っています。

---

## 1. 記入済みの見本（登場する名前・会社・数字はすべて架空です）

走り書きから、実際にこの形になります。

### 材料（走り書きの例）

```
8/7 定例
田中・鈴木・佐藤
・新パンフ、B案でいくことに。写真は差し替え
・鈴木さん、印刷所に見積もり。来週まで
・佐藤さん、写真の選定 8/20
・値上げの話→もうちょい様子見。次回
・次回 8/21 14時
```

### 仕上がり

```
■ 定例会議
日時：2026年8月7日　／　出席者：田中、鈴木、佐藤

【決定事項】
1. 新しいパンフレットはB案で進める
2. パンフレットの写真は差し替える

【宿題】
| 内容 | 担当 | 期日 |
|---|---|---|
| 印刷所へ見積もりを依頼する | 鈴木 | 来週まで〈要確認〉 |
| 差し替える写真を選ぶ | 佐藤 | 8月20日 |

【持ち越し】
- 値上げの実施時期（今回は結論を出さず、次回に持ち越し）

次回：2026年8月21日 14時

――――――
◆ 要確認（1件）
- 鈴木さんの見積もり依頼の期日が「来週まで」となっています。具体的な日付をご確認ください。
```

**この見本で見てほしいところ**

- 「もうちょい様子見」は、決定事項ではなく**持ち越し**に入っています
- 「来週まで」は日付に直さず、**原文のまま＋`〈要確認〉`** で残しています
- 走り書きの「新パンフ、B案でいくことに。写真は差し替え」は、**2つの決定**に分けています（1文に2つ入っていると、片方が見落とされるため）

---

## 2. 曖昧な言葉の扱い方

### 期日を表す言葉

**次の言葉は、日付に直しません。原文のまま残して `〈要確認〉` を付けます。**

来週まで／今週中／今月中／月末まで／早めに／なるはや／落ち着いたら／次回まで／近いうちに

理由：起点の日が書き手にしか分からないためです。「来週まで」が金曜締めなのか翌週いっぱいなのかで、担当者の動き方が変わります。

**逆に、日付として扱ってよいもの**：`8/20`・`8月20日` のように、**月と日がそろって書かれているもの**。`〈要確認〉` は付けません。

**「20日」のように日だけ書かれているものは、日付として扱いません。** 会議の月と同じだと**推測はできますが、断定はできない**ので、`20日〈要確認：何月か〉` と印を付けます（理由：月をまたぐ会議——月末の定例で翌月の話をしている場合——に、1か月ずれた期日が確定として残るためです。推測で埋めない、がこのスキルの背骨です）。

### 決まったのかどうかを表す言葉

| メモの書き方 | どの箱に入れるか |
|---|---|
| 〜することにした／〜で合意／〜に決定 | 決定事項 |
| 〜でいこう／〜でOK／〜で進める | 決定事項 |
| 〜の方向で／〜がよさそう／たぶん〜 | **持ち越し**（まだ決まっていません） |
| 〜は保留／様子見／次回 | 持ち越し |
| 〜しておいて／〜お願いします／〜やります | 宿題 |

迷ったら**持ち越し**に入れます（理由：決まっていないことを「決まった」と書く事故のほうが、その逆より重いためです）。

### 名前の書き方

- メモに「鈴木さん」「鈴木」「S さん」が混在していたら、**いちばん多く出てくる書き方にそろえる**
- 役職だけ（「部長」「先方」）で書かれていて、誰か特定できないときは `〈要確認〉` にする

---

## 3. 文字起こしが材料のときのコツ

文字起こしは、走り書きの5倍〜20倍の分量になります。次の順で読むと速く終わります。

1. **まず終わりの5分を読む。** 決定事項とその日の宿題は、たいてい最後にまとまっています
2. 次に、全体を通して「じゃあ」「ということで」「お願いします」の前後を拾う。結論と依頼はこの3語の近くに出ます
3. 最後に頭から流し読みして、拾い漏れた決定が無いか確かめる

**相づち・言い直し・雑談は、最初から拾いません。** 「えーと」「はい、はい」「そうですね」を丁寧に整えても、議事録の役には立ちません。

---

## 4. この議事録を配る前の確認（3つだけ）

1. **要確認の一覧が空でないなら、それを先に埋めてから配る**（`〈要確認〉` が残ったまま配ると、受け取った人は何を確認すればよいか分かりません）
2. **人の評価に関わる発言が残っていないか**を見る（「〇〇さんの詰めが甘い」のような発言は、決定でも宿題でもありません。3つの箱に入らないので、そもそも書かないのが正しい形です）
3. **社外の人が読む議事録なら、社内の呼び名・略語を開いておく**（「例の件」「A社さんの例のやつ」は、半年後には社内でも通じません）
