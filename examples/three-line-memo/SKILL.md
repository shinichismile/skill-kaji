# 3行メモ

> **これは「スキル鍛冶」に同梱された見本です。** そのまま使えますし、自分用に書き換えて使ってもかまいません。
> 「良いスキルはこういう形」を見るための完成品として置いてあります。

読んだものを、あとで思い出せる**3行のメモ**に変えるスキル。

「あの記事、良かったんだけど何が書いてあったっけ」を無くすのが目的です。長い要約は作りません。長い要約は、結局もう一度読み直すのと同じだからです。

**むいている場面**：記事・資料・動画を読んだ（見た）直後の記録。
**むいていない場面**：正確な引用や逐語が要る用途（原文にあたってください）。長文の要約そのものが欲しい場合（このスキルは3行に削るのが仕事です）。

## 手順

1. **中身を最後まで読む**（理由：冒頭だけで要点を決めると、結論が後半にある文章で必ず外すため）
2. **3行それぞれの中身を決める**（理由：形を固定すると、見返したときに探す場所が毎回同じになり、読む速さが変わるため）
   - 1行目＝**何の話か**（分野と対象。「誰に向けた何の話か」が分かる書き方にする）
   - 2行目＝**いちばんの要点**（その文章がいちばん言いたかったこと1つだけ）
   - 3行目＝**自分はどうするか**（試すこと・使う場面・様子見の理由）
3. **各行を60字以内にする**（理由：1行が長いと、結局読み返すのに時間がかかり、メモの意味が消えるため）
4. **出典の名前と日付を1行添える**（理由：あとで元をたどれないメモは、正しいかどうか確かめられなくなるため）

## 出力の型

```
【3行メモ】〈題名〉
出典：〈書いた人・媒体名／日付〉

1. 〈何の話か〉
2. 〈いちばんの要点〉
3. 〈自分はどうするか〉
```

## 判断ルール（分かれ道）

| 場面 | どうするか | 理由 |
|---|---|---|
| 要点が2つ以上あって選べない | いちばん**行動が変わるもの**を選ぶ | メモの目的は理解ではなく、次の行動を変えること |
| 自分がどうするか思いつかない | 3行目を「今は使わない。〈こういう場面〉が来たら見返す」と書く | 空欄にすると、見返したとき判断をやり直すことになる |
| 読んだものが長い（本・長編記事） | 章ごとに3行メモを作り、最後に全体の3行メモを1つ作る | 1本にまとめようとすると、どの行も抽象的になって役に立たない |
| 事実か意見か曖昧な内容 | 2行目の末尾に「（書き手の意見）」と添える | 意見を事実として覚えてしまうのが、いちばん危ない失敗 |

## 合格ライン

- [ ] `〈 〉` の穴（未確定の箇所）が1つも残っていない＝そのまま渡せる状態
- [ ] 3行がそれぞれ60字以内におさまっている
- [ ] 1行目だけ読んで、何の話か分かる
- [ ] 3行目に、自分の行動が書いてある（感想で終わっていない）
- [ ] 出典と日付が入っている

## やってはいけないこと

- **4行以上書かない。** 増やすと、次から読み返さなくなります
- **「勉強になった」「参考になった」で終わらせない。** 感想は3行目ではありません。行動を書きます
- **読んでいない部分について書かない。** 分からない部分は「〈この章〉は未読」と正直に書きます
- **元の文章を長く引き写さない。** 引用するなら1文まで、かぎ括弧でくくって出典を添えます
