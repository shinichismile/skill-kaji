# やさしい文章に直す（yasashii-bunsho）

> **これは「スキル鍛冶」に同梱された見本です（貼るだけ形＝本文だけで完結し、どのAIでも動く書き方の見本）。** そのまま使えますし、自分用に書き換えてもかまいません。

役所の通知・会社のお知らせ・規約・案内文のような**硬くて伝わらない文章**を、意味を変えずにほどくスキル。

「間違ってはいないのに、読んでもらえない」文章を、**最後まで読める文章**に変えるのが目的です。

**むいている場面**：お知らせ・案内・説明文・社内文書・メール。相手に行動してほしい文章ほど効きます。
**むいていない場面**：契約書・約款・法令など、**文言そのものに効力がある文章**（読み手向けの補足説明を別に作るのが正しいやり方です。本文は書き換えないでください）。詩・小説など、表現そのものが価値である文章。

**このスキルは、貼り付けられた文章だけで完結します。** ファイルを開く必要も、インターネットで調べる必要もありません。文章を1つ受け取って、書き直したものを返すだけです。

## 進め方

### 1. 相手と、やさしさの水準を決める

「誰が読むか」で、やさしくする度合いが変わる（理由：日本語を学んでいる人向けの文章と、忙しい社会人向けの文章は、ほどき方がまるで違うためです）。

指定が無ければ、**B（一般のおとな向け）で書く。** 他の水準にも直せることは、**出力の型の「気になったところ」の下に1行添えて伝える**（理由：本文の前に置くと、読む人が本題に入る前に選択を迫られるためです。まず読める物を見せてから、選べることを伝えます）。

| 水準 | 読む人 | どこまでほどくか |
|---|---|---|
| A：やさしい日本語 | 日本語を学んでいる人・子ども | 1文20字程度。**下の追加ルール**を守る |
| B：一般のおとな向け（既定） | 忙しい社会人・一般の住民 | 1文40〜60字。専門用語は言い換えるか、そのあとに短い説明を足す |
| C：やわらげるだけ | 同業者・社内 | 1文60字以内。**用語は変えない。**下の追加ルールを守る |

**水準Aだけの追加ルール**

- **ふりがなは、漢字のあとに丸括弧で置く**（例：`申込（もうしこみ）`）。ルビ記号や振り仮名の記法は使わない（理由：貼り付ける先——メール・チラシ・掲示物——によっては、特殊な記法が崩れて読めなくなるためです）
- **ふりがなを付けるのは、小学校で習わない漢字**。全部に付けると、かえって読みにくくなります
- **和暦は、西暦を併記する**（例：`令和8年（2026年）`）。逆に元の文が西暦だけなら、そのまま西暦で通す（理由：日本語を学んでいる人にとって元号は未知の体系で、西暦が無いと年が特定できないためです）
- **敬語は「です・ます」まで下げる。** 尊敬語・謙譲語は使わない
- 曜日・時刻は数字で書く（`午後3時` ではなく `15時`）

**水準Cだけの追加ルール**

- **専門用語・略語・社内の呼び名は、1つも変えない**（理由：Cを選ぶ相手は用語が通じる人なので、言い換えるとかえって遠回りになります）
- 変えてよいのは**1文の長さ・語順・敬語の層・冗長な言い回し**の4つだけ
- そのため、**Cでは「言い換えた言葉」の表がほぼ空になります。** 空でも表は残し、「用語の言い換えなし（水準Cのため）」と書く

### 2. 落としてはいけない情報を、先に書き出す

**書き直しに入る前に、元の文から次のものを抜き出して並べる**（理由：やさしくする作業は「削る」作業なので、勢いがついたまま進めると、いちばん大事な条件や期限が一緒に削られるためです。先に守るものを決めてから削ります）。

抜き出すもの：
- **数字**：金額・日付・期限・回数・年齢・人数
- **条件**：「〜の場合は」「〜を除く」「〜に限り」
- **打ち消し**：「〜できません」「〜は対象外です」
- **主語**：誰が誰に対してするのか（元の文で省かれていることが多い箇所）

### 3. 書き直す

水準に合わせて書き直す。やることは4つだけです。

1. **1文を短く切る**（理由：読みにくさの原因の大半は、語彙ではなく1文の長さです）
2. **むずかしい言葉を、ふだんの言葉に置き換える**（例：「申請」→「申し込み」、「速やかに」→「すぐに」）
3. **置き換えられない専門用語は、残したうえで短い説明を足す**（理由：正式名称を消すと、窓口で聞き返すときに困るためです）
4. **順番を「相手のすること」から先に書く**（理由：お知らせ文は、経緯より先に「何をすればいいか」が要るためです）

**定型の挨拶は、削ってよい。** 「拝啓」「時下ますますご清栄のこととお慶び申し上げます」「何卒ご了承賜りますよう」のような決まり文句は、手順2の「守る情報」に入りません（理由：これらは中身を運んでいない、儀礼の枠です。枠を外しても意味は1つも減りません）。

ただし、**次の2つは削らない**：**誰に宛てた文か**（宛名）と、**問い合わせ先**。この2つは儀礼ではなく、読む人が次に動くための情報です。

### 4. 照合する

手順2で書き出した情報を、**書き直した文と1つずつ突き合わせる**（理由：意味が変わっていないことは、読み返した印象ではなく、突き合わせでしか確かめられないためです）。

**1つでも落ちていたら、書き直しに戻る。**

### 5. 対応表を添えて出す

言い換えた言葉を表にして添える（理由：受け取った人が「この言い換えでいいのか」を1分で判断できるようにするためです。判断できない書き直しは、結局そのまま使われません）。

## 判断ルール（分かれ道）

| 場面 | どうするか | 理由 |
|---|---|---|
| 元の文の意味が、そもそも読み取れない | 書き直さず、**どこが読み取れないかを指摘して聞く** | 分からないまま書き直すと、間違った意味で断言された文ができあがる |
| 専門用語を言い換えると意味がずれる（法律用語・制度の名前など） | **正式名称を残し、直後に「＝〜のこと」と短く足す。ただし、足す説明は元の文の中に書かれているものだけを使う** | 名前が変わると、調べるときも問い合わせるときも通じなくなる |
| **専門用語の説明が、元の文のどこにも書かれていない** | 用語はそのまま残し、`〈この言葉の説明が元の文にありません〉` と印を付けて聞く。**自分の知識で説明を足さない** | 「年間契約＝1年分をまとめて払うこと」は一見あたりまえですが、**そのサービスで実際にそうとは限りません**。補った説明が事実と違えば、やさしくしたぶんだけ確実に誤解が広がります |
| 元の文に、条件が書かれていない箇所がある | 補わずに `〈ここは元の文に書かれていません〉` と印を付けて返す | 親切心で補った条件が、事実と違ったときの被害が大きい |
| **「下記」「別紙」「上記のとおり」など、指し示す先が渡された文の中に無い** | その言葉を残さず、`〈下記の内容が渡された文に含まれていません。電話番号・窓口をお知らせください〉` と印を付けて聞く | 「下記までお問い合わせください」で終わる案内文が、いちばん多い事故です。やさしく書き直したところで、問い合わせ先が無ければ読む人は動けません |
| 敬語が過剰（二重敬語・へりくだりすぎ） | 「です・ます」まで下げる | 敬語の層を重ねるほど、誰が何をするのかが見えなくなる |
| 元の文が長い（1000字を超える） | 見出しを付けて区切り、その旨を伝える | 長い文章は、言い換えだけでは読みやすくなりません |

## 出力の型

```
【やさしくした文章（水準：〈A／B／C〉）】

〈書き直した文章〉

【守った情報の照合】
- 〈項目〉：〈元の文の値〉 → 〈書き直した文から、その値を含む一文をそのまま引用〉
- 〈項目〉：〈元の文の値〉 → 〈同上〉

　※ 書き方の例：
　　- 期限：9月30日 → 「9月30日までに年間契約に変えた人は、1年間は今の値段のままです。」
　　- 打ち消し：キャンペーン価格の人は対象外 → 「今キャンペーン価格の人は、この特典を使えません。」

【言い換えた言葉】
| 元の言葉 | 書き直した言葉 |
|---|---|
| 〈…〉 | 〈…〉 |

【気になったところ】
- 〈元の文が曖昧だった箇所、確認したほうがよい箇所。無ければ「なし」〉

※ この文章は水準〈選んだ水準〉で書きました。〈残り2つの水準と、その向き先〉にも直せます。
```

**最後の1行（他の水準への案内）は、毎回入れます。** 書き方の例：

> ※ この文章は水準B（一般のおとな向け）で書きました。日本語を学んでいる方に配るなら水準A（ふりがな付き・1文20字程度）、社内の方だけに送るなら水準C（用語はそのまま）にも直せます。

## 合格ライン（これを満たしたら完成）

- [ ] 金額・日付・期限・条件・打ち消しが、1つも落ちていない（照合欄で確かめてある）
- [ ] 元の文に無い情報を足していない
- [ ] 1文の長さが、選んだ水準の目安に収まっている
- [ ] **選んだ水準の追加ルールを守っている**（Aならふりがなの置き方と西暦併記、Cなら用語を1つも変えていない）
- [ ] 言い換えた言葉の対応表が付いている（水準Cで空になる場合も、表は残してある）
- [ ] **他の水準にも直せることが、末尾に1行入っている**
- [ ] `〈 〉` の穴（未確定の箇所）が1つも残っていない＝そのまま使える状態になっている
      ※ `〈ここは元の文に書かれていません〉` の印は、意図して残すものなので穴には数えません

## やってはいけないこと

- **やさしくするために、条件や例外を削らない。** 「原則〜です（ただし〜を除く）」の括弧の中が、いちばん削られやすく、いちばんもめます
- **元の文に無い情報を足さない。** 「たぶんこういう意味だろう」で足した1行が、いちばん危ない
- **数字を丸めない。** 「1,850円」を「約2,000円」にしない
- **契約書・約款の本文を書き換えない。** 説明文を別に作ります
- **「わかりやすくなりました」と自己申告で終わらせない。** 照合欄で示します
