# 読み替え表（お使いのAI別の置き場所と呼び方）

**ツールごとに違う情報は、このファイルだけに書いてあります。** ほかのファイルは「役割」で書いてあるので、具体的な場所やコマンドが必要になったら、ここを開いて読み替えてください。

**AIへ**：利用者に保存先を案内する前に、**必ず「どのAIをお使いですか」を聞いてから**この表の該当行を渡すこと。推測で答えない。

**AIへ（もう1つ・停止規定7）**：この表は**起点であって、答えの根拠ではありません**。検索できる環境なら、案内する前に該当ツールの公式ドキュメントで最新を確かめてから答えること。この分野のUI・プラン条件は月単位で変わります（実例：2026年8月、ChatGPTのSkillsはサイドバー直下からPlugins配下へ移動し、対象プランの条件も付いていた）。公式が「使えない」としているものを「使える」と案内しない。

## 注記

1. **ここに無いAIをお使いの場合**：そのAIの公式ドキュメントで「skills」を探してください。対応ツールの公式一覧は agentskills.io の Client Showcase にあります
2. **この表は2026年8月時点のものです。3か月をめどに見直してください。** この分野は動きが速く、置き場所や呼び方は変わります
3. **スキル一覧を確認するコマンド**（重複チェックや、入ったかの確認に使う）：Claude Code は `/skills`、Antigravity CLI は `/skills`、GitHub Copilot は チャットで `/skills`（またはコマンドパレットの `Chat: Open Customizations`）。一覧の手段が無いAIでは、利用者に画面の一覧を貼ってもらう

## 隠しフォルダ（`~/.claude` など）の開き方

`~` は「あなたのユーザーフォルダ」のことです。デスクトップや書類フォルダと同じ階層にある、自分の名前がついたフォルダだと思ってください。

**`.claude` や `.agents` のように先頭に点が付くフォルダは「隠しフォルダ」で、普段は画面に出てきません。見つからなくても壊れていません。**

- **Windows**：エクスプローラーを開き、上のアドレス欄に `%USERPROFILE%\.claude\skills` と打ってEnter（`.agents` などに置く場合は、その部分を読み替えてください）
- **Mac**：Finderを開き、`Command + Shift + G` を押して、出てきた欄に `~/.claude/skills` と打ってEnter

`skills` フォルダが無ければ、その場で新規作成してかまいません。

## 反応しないときの3段階（この順で試す）

1. **スキル一覧を読み込み直す**（上の注記3のコマンド、または Antigravity なら `/skills reload`）
2. **新しいチャット・新しいセッションを開く**（作った直後の同じ会話では、まだ読み込まれていないことがあります）
3. **アプリを閉じて開き直す**（ここまでやって駄目なら、置き場所が1階層ずれている可能性が高いです）

## 公式のスキル作成機能（あれば併用してよい）

お使いのAIに公式のスキル作成機能があれば、併用してかまいません（Codex は `$skill-creator`、ChatGPT は `@skill-creator`。Antigravity や Cursor にも同種のものがあります）。この鍛冶場は、それが無くても最後まで完結するように書いてあります。
