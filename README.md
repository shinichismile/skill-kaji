# スキル鍛冶（skill-kaji）

繰り返している仕事の型を、AIが毎回そのとおりに再現できる「あなた専用のスキル」に打ち直します。
**15分〜30分で1本作るクイックコース**と、世の中の似たスキルを調べて超える設計にする**匠コース（7工程）**の2本立て。
作ったスキルはAI自身が試しに動かして点検し、詰まった箇所と直し方まで報告します。プログラミングの知識は要りません。

## スキルって何ですか

スキルは、AIに渡す**あなた専用のレシピカード**です。テキストファイル1枚でできています。
一度作れば、次からは「請求書作って」のひと言で、あなたの手順・あなたの言い回し・あなたの注意点どおりに仕上がります。同じ説明を毎回やり直す時間が丸ごと消えます。

**必要なもの**：スキルを読み込めるAIツール（Claude Code、claude.ai、ChatGPT、Codex、Cursor、GitHub Copilot など）。

## 入れ方

**入れ方は3通りあります。上から順に簡単です。**

- **入れ方0：AIに頼む（いちばん簡単）** — Claude Code・Codex など、パソコンの中で動くAI
- **入れ方A：フォルダに自分で置く** — 同上のAIで、手動でやりたい方
- **入れ方B：画面からアップロードする** — claude.ai・ChatGPT のチャット画面

### 入れ方0：AIに頼む（いちばん簡単）

チャットにこう打つだけです。

> このスキルを入れて → https://github.com/shinichismile/skill-kaji

AIがダウンロードして、正しい置き場所に入れてくれます。
**zipで受け取った方も同じです。** zipファイルの場所を伝えて「このzipをスキルとして入れて」と頼めば、展開も配置もAIがやります（二重フォルダの罠もAIが自分で避けます）。

入ったかの確認は、**新しいチャットを開いて「スキル作りたい」**。返事が来れば成功です。

### 入れ方A：フォルダに自分で置く

**1. zipを展開すると、二重のフォルダになっています**

展開すると `skill-kaji-v0.1.0` のような箱ができ、**その中にもう1つ `skill-kaji` フォルダ**が入っています。
**移動させるのは、必ず内側の `skill-kaji` フォルダです。** ここを間違えると、入れたのに一生反応しません（いちばん多い失敗です）。

**2. スキルの置き場所に入れます**

置き場所はお使いのAIによって違います。**`references/tool-map.md`（読み替え表）で、ご自分のAIの行を見てください。**
例：Claude Code なら `~/.claude/skills/skill-kaji/`。

`~` は「あなたのユーザーフォルダ」のことです。デスクトップや書類フォルダと同じ階層にある、自分の名前がついたフォルダだと思ってください。

**※ `.claude` や `.agents` のように先頭に点が付くフォルダは「隠しフォルダ」で、普段は画面に出てきません。見つからなくても壊れていません。**

- **Windows**：エクスプローラーを開き、上のアドレス欄に `%USERPROFILE%\.claude\skills` と打ってEnter
- **Mac**：Finderを開き、`Command + Shift + G` を押して、出てきた欄に `~/.claude/skills` と打ってEnter

（`skills` フォルダが無ければ、その場で新規作成してかまいません）

**3. 入ったかどうかの確認**

`...\skills\skill-kaji` を開いて、**`SKILL.md` というファイルが見えれば成功**です。
見えずに `skill-kaji` フォルダがもう1つ入っていたら、**1階層深く入れてしまっています**。内側のフォルダを引き上げてください。

### 入れ方B：画面からアップロードする

**フォルダをzipにして、画面から入れます。**

- **claude.ai**：サイドメニューの **Customize（カスタマイズ）→ Skills** →「Create skill」→「Upload a skill」で**zipをアップロード**
  （**Freeプランでも使えます**。前提＝コード実行・ファイル作成の機能がONであること。Free/Pro/Maxは Settings → Capabilities で確認）
- **ChatGPT**：サイドバーの **Plugins → Skillsタブ → Create → Upload from your computer**
  （**2026年8月時点で Business／Enterprise／Healthcare／Edu 向けの機能です。個人の Free・Go・Plus・Pro ではまだ使えません**）

詳しい場所は `references/tool-map.md`（読み替え表）にまとめてあります。

## 最初の一言

新しいチャットを開いて、こう話しかけてください。

> **スキル作りたい**

あとは聞かれたことに答えるだけで、1本目が仕上がります。
（「この作業をスキルにして」「スキル化したい」「毎回同じ説明をするのが面倒」でも同じように始まります）

反応しないときは、名前を直接呼んでみてください（`/skill-kaji` など。呼び方はAIによって違います＝読み替え表を参照）。

## 使い方（何が起きるか）

**はじめての1本（クイックコース・15分〜30分）**

1. 「スキル作りたい」と話しかける → コース・使っているAI・作りたい作業の3つを聞かれます
2. クイックを選ぶと、3〜4の質問（今のやり方／合格の条件／どう頼みたいか。作業がまだ曖昧なときだけ、どの作業かも）に答えるだけ。**過去に作った実物（見本）が1つあると精度が跳ね上がります**
3. AIがスキルを作って設置し、**その場で試しに動かして**、詰まった箇所と直し方を報告してきます
4. 最後にあなたが**新しいチャットで動作テスト**をして完成。作品ノート（あなたの制作記録）に1行残ります

**本気の1本（匠コース・7工程）**

人に配る・売ることも視野に入るならこちら。①聞き切る →②器を選ぶ →③**世の中の似たスキルを実際に調べる** →④どこで超えるかを決める →⑤作る →⑥**鍛える（AIが試しに動かして不具合と直し方を出し、テストの記録を残しながら点検）** →⑦世に出す、まで伴走します。クイックで作った1本を後から匠で鍛え直すこともできます。

**工程⑦の出口は2つ（どちらも同格です）**

- **自分用のまま使う** — これで完結です。配らなくてもかまいません
- **配る・売る** — 点検に合格したものだけをzipにまとめます。あなたの作品を他の人がカスタマイズ・再配布・販売してよいかは、**AIがあなたに質問して**、答えを利用条件（LICENSE）に落とします。売るのも自由です（値段はあなたが決めます。AIは値付けの相談には乗りません）

---

## うまくいかないとき（多い順）

1. **入れる場所が1階層ずれている** — いちばん多い原因です。`...\skills\skill-kaji` を開いて `SKILL.md` が直接見えるか確かめてください。`skill-kaji` フォルダがもう1つ入っていたら、内側を引き上げます
2. **読み込み直していない** — スキル一覧を読み込み直す（Claude Code なら `/skills`）→ 新しいチャットを開く → それでも駄目ならアプリを閉じて開き直す、の順で試してください
3. **話しかけただけでは出てこない** — AIによっては、名前を直接呼ばないと出てこない仕様です（`/skill-kaji` など）。それでも普通の言葉で呼び出したいときは、**実際に打った言葉をAIに伝えてください。** 発動の合図（description＝どんな言葉で頼まれたら使うかを書いた欄）を直してくれます

## 中身

| ファイル | 何が書いてあるか |
|---|---|
| `SKILL.md` | 本体。2つのコースの進め方 |
| `references/tool-map.md` | **読み替え表**。AIごとの置き場所・呼び方・一覧の出し方 |
| `references/templates.md` | SKILL.mdのひな型（最小形／フル形）と、AIをまたいで使うときの書き分け |
| `references/research-guide.md` | 似たスキルの調べ方・比較表・超え方の設計 |
| `references/forge-and-release.md` | 試し動かし・点検・混入チェック（見せてはいけない情報が紛れていないかの確認）・zipにまとめる手順 |
| `LICENSE.md` | 利用条件 |

**同梱の見本4本**（そのまま使えます）

| 見本 | 何をするもの | 誰向けか |
|---|---|---|
| `examples/three-line-memo/` | 読んだものを3行のメモにする | 誰でも（貼るだけ形） |
| `examples/yasashii-bunsho/` | 硬い文章をやさしく書き直す | 誰でも（貼るだけ形） |
| `examples/kaigi-memo/` | 会議メモを議事録にする | 会議の記録を取る方（資料つき形） |
| `examples/commit-note/` | 変更内容からコミット文を書く | **プログラムを書く方向け。使わない方は飛ばして大丈夫です**（コマンド形） |

見本4本は、この鍛冶場の工程（調査→設計→試し動かし→点検）を実際に通して作った実物です。**「本文だけで完結する形」と「資料を分ける形」で書き方がどう違うか**を見比べる教材にもなります。

**見本を使いたいときは**、そのフォルダ（例：`examples/yasashii-bunsho/`）を**スキル置き場の直下にコピー**して入れてください（`examples/` の中に置いたままでは読み込まれません）。ブラウザのAIをお使いなら、そのフォルダをzipにしてアップロードしてください。

## どのAIで使えますか

スキルの形式（SKILL.md）はオープンな規格で、**2026年8月時点で46のツール**が対応をうたっています（公式一覧＝agentskills.io の Client Showcase）。**数字と顔ぶれは動きが速いので、3か月をめどに公式一覧で見直してください。**

**Claude Code を基準に書いた手順書です。** Codex・Antigravity CLI・Cursor・GitHub Copilot でも同じ手順で作れます（入れる場所だけ違います。読み替え表をご覧ください）。claude.ai・ChatGPT のチャット画面でも作れますが、zipのアップロード方式になり、記録の保存と混入チェックは手作業になります（claude.ai は Free プランでも使えます。ChatGPT の Skills は 2026年8月時点で Business／Enterprise／Healthcare／Edu 向けで、個人の Plus・Pro は対象外です）。

**どのAIでも、動作の確認はご自身の環境で行ってください。**

置き場所・呼び方の一覧は `references/tool-map.md` にあります。
