# スキル鍛冶（skill-kaji）

繰り返している仕事の型を、AIが毎回そのとおりに再現できる「あなた専用のスキル」に打ち直します。
**15分〜30分で1本作るクイックコース**と、市場の類似を調べて超える設計にする**匠コース（7工程）**の2本立て。
作ったスキルはAI自身が試しに動かして点検し、不具合と直し方の案まで出します。プログラミングの知識は要りません。

**必要なもの**：対応するAIツール（Claude Code など、SKILL.md 形式のスキルを読み込めるもの）。

## 入れ方

1. この `skill-kaji` フォルダを、次の場所に置いてください
   - **どこで作業していても使いたい** → `~/.claude/skills/skill-kaji/`
   - **特定の仕事のフォルダでだけ使いたい** → そのフォルダの `.claude/skills/skill-kaji/`
2. AIのアプリを一度閉じて、開き直してください

※ `~` は「あなたのユーザーフォルダ」のことです。デスクトップや書類フォルダと同じ階層にある、自分の名前がついたフォルダだと思ってください。

**※ `.claude` は先頭に点が付く「隠しフォルダ」で、普段は画面に出てきません。見つからなくても壊れていません。** 開き方はこちらです。

- **Windows**：エクスプローラーを開き、上のアドレス欄に `%USERPROFILE%\.claude\skills` と打ってEnter
- **Mac**：Finderを開き、`Command + Shift + G` を押して、出てきた欄に `~/.claude/skills` と打ってEnter

（`skills` フォルダが無ければ、その場で新規作成してかまいません）

## 最初の一言

新しいチャットを開いて、こう話しかけてください。

> **スキル作りたい**

あとは聞かれたことに答えるだけで、1本目が仕上がります。
（「この作業をスキルにして」「スキル化したい」「毎回同じ説明をするのが面倒」でも同じように始まります）

## 使い方（何が起きるか）

**はじめての1本（クイックコース・15分〜30分）**

1. 「スキル作りたい」と話しかける → コース・使うAI・作りたい作業の3つを聞かれます
2. クイックを選ぶと、3〜4の質問（今のやり方／合格の条件／どう頼みたいか。作業がまだ曖昧なときだけ、どの作業かも）に答えるだけ。**過去に作った実物（見本）が1つあると精度が跳ね上がります**
3. AIがスキルを作って設置し、**その場で試しに動かして**、詰まった箇所と直し方を報告してきます
4. 最後にあなたが**新しいチャットで発動テスト**をして完成。作品ノート（あなたの制作記録）に1行残ります

**本気の1本（匠コース・7工程）**

人に配る・売ることも視野に入るならこちら。①聞き切る →②器を選ぶ →③**世の中の似たスキルを実際に調べる** →④どこで超えるかを決める →⑤作る →⑥**鍛える（AIが実走検証して不具合と改修プランを出し、証跡つきで検品）** →⑦世に出す、まで伴走します。クイックで作った1本を後から匠で鍛え直すこともできます。

**工程⑦の出口は2つ（どちらも同格です）**

- **自分用のまま使う** — これで完結です。配らなくてもかまいません
- **配る・売る** — 検品に合格したものだけをzipに梱包します。あなたの作品を他の人がカスタマイズ・再配布・販売してよいかは、**AIがあなたに質問して**、答えを利用条件（LICENSE）に落とします。売るのも自由です（値段はあなたが決めます。AIは値付けの相談には乗りません）

**うまくいかないとき**

- 発動しない → アプリを閉じて開き直し、新しいチャットでもう一度。それでもダメなら、実際に打った言葉をAIに伝えると、発動の合図（description）を直してくれます
- 詳しい手順や検品のやり方 → `SKILL.md` と `references/` の各ファイルに全部書いてあります（AIが必要なときに自動で読みます）

## 中身

| ファイル | 何が書いてあるか |
|---|---|
| `SKILL.md` | 本体。2つのコースの進め方 |
| `references/templates.md` | SKILL.mdのひな型（最小形／フル形）とマルチAI対応の書き分け |
| `references/research-guide.md` | 似たスキルの調べ方・比較表・超え方の設計 |
| `references/forge-and-release.md` | 実走検証・検品・混入チェック・梱包の手順 |
| `examples/three-line-memo/` | 完成品の見本①「3行メモ」（どのAIでも動く汎用形） |
| `examples/yasashii-bunsho/` | 完成品の見本②「やさしい文章」（汎用形・チャット貼り付けだけで完結） |
| `examples/kaigi-memo/` | 完成品の見本③「会議メモ→議事録」（両対応形・referencesの分け方の見本） |
| `examples/commit-note/` | 完成品の見本④「コミットメッセージ係」（Claude Code専用形・コマンド実行を使う書き方の見本） |
| `LICENSE.md` | 利用条件 |

見本4本は、この鍛冶場の工程（市場調査→超え方の設計→実走検証→検品）を実際に通して作った実物です。そのまま使えますし、**「専用形と移植形で書き方がどう違うか」を見比べる教材**にもなります。

**見本を使いたいときは**、そのフォルダ（例：`examples/yasashii-bunsho/`）を `~/.claude/skills/` の**直下にコピー**して入れてください（`examples/` の中に置いたままでは読み込まれません）。

## 他のAIでも使えます

スキルの形式（SKILL.md）はオープンな規格で、2026年8月時点で40を超えるツールが対応をうたっています。
ただしツールごとに読み込みの挙動は違うので、**動作検証はご自身が使うAIで必ず行ってください。**

## 利用条件

全部自由です。改造も、再配布も、販売も、許可なくどうぞ。
**このスキルで作った作品は完全にあなたのもので、売るのも自由です。** 詳しくは `LICENSE.md` をご覧ください。
